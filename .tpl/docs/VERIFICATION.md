# 验证方法

自动检查：typecheck、lint、test、build。数据测试核对商品唯一性、分类关联、图片存在、双语完整、套餐引用与价格、课程时长与模块。真实运行默认中文与 /en 的各页，未知 slug 应为 404。

三端检查视口为 PC 1440×1000、平板 834×1180、手机 390×844，并补测 320px。截图尺寸按图片解码结果登记，浏览器滚动条和缩放可能令实际截图小于 CSS 视口。检查根内容宽度与 scrollWidth，而非用隐藏溢出来掩盖问题。

手工检查菜单、分类、价格、排序、商品详情、套餐、课程切换、FAQ、购物车数量与价格、表单无效/有效提示、语言切换保留参数及锚点。弹窗检查 Escape、Tab 焦点循环、背景锁定与关闭恢复。滚动检查整页、横向货架、评价与弹窗内部滚动。

动效逐项检查开场装货与双向揭幕、标题遮罩、错峰、立体包装/书架倾斜、手机横向货架、小票更新、订单带、橱窗固定缩放、滚动开盒、课程联动、数字增长、图表、评价拖拽回弹、文字点亮、图片揭示、FAQ 与路由过渡。静态截图不能证明全量动效一致。源码摘要匹配的实际报告在 reports/verification.json；未执行或存在差异须如实说明。
