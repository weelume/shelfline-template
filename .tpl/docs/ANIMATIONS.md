# 动效清单

参考基线包含桌面与手机实际浏览，以及公开渲染内容/样式核对。开场装货约 2.6 秒，物件错峰落下约 0.55 秒，随后上下幕分离；本实现整个开场约 3.3 秒，当前标签页完成后不重复。

标题从下方 108% 遮罩内移入，1 秒，逐词或中文语义行错峰；图片 1.35 秒裁切揭示和 1.9 秒缩放，滚动视差。桌面书架约 rotateX(7deg)/rotateY(-16deg)，指针驱动柔和跟随；商品悬停上移、包装回弹。小票每 2.8 秒切换，离屏/页面隐藏时停止更新；订单带循环，聚焦/悬停暂停。

手机在 809px 及以下改为单排横向货架、常显商品标签，原生触控和键盘横移。桌面橱窗高度 230svh，内部固定 100svh，随滚动缩放；手机改自然布局。盒盖按滚动从 0 到 -118 度，内容上移。课程目录悬停/聚焦/点击联动，数字 1.6 秒增长，图表错峰；评价支持水平拖动与弹性回弹。工作室叙事分段点亮，FAQ 0.5 秒展开，标签按钮文字翻动，路由标签形遮幕横移。

尊重 prefers-reduced-motion。当前实现不主张与原站全部物理参数、光照、包装几何、逐帧轨迹完全一致；具体实际验证与差异以 reports/verification.json 为准。没有用静态图片替换可播放视频。
