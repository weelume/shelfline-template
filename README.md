# Shelfline 创作者数字商店

独立 React / Next.js 双语数字商品展示模板。默认中文，英文路径 `/en`。

运行 `corepack pnpm install --frozen-lockfile`，`corepack pnpm dev`，访问 http://localhost:43410。用 Ctrl+C 停止服务。

检查：`corepack pnpm typecheck`、`corepack pnpm lint`、`corepack pnpm test`、`corepack pnpm build`。生产构建在本地 Linux 文件系统执行。

本地购物车仅保留在内存中，刷新即清空；表单只做本地校验。无真实支付、账户、邮件或付费文件交付。素材权利边界见 `.tpl/docs/LICENSE.md`。

先阅读 `.tpl/README.md`、`.tpl/template.json`、`.tpl/project.json`，修改入口见 `.tpl/customization.json`。
